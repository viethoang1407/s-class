📋 I. THÔNG TIN TỔNG QUAN

1.1. Tên dự án

Study 1.0 - Hệ thống quản lý lớp học trực tuyến

1.2. Mô tả

Ứng dụng web hỗ trợ giáo viên quản lý lớp học, tạo bài kiểm tra, điểm danh, chấm điểm và tương tác với học sinh. Học sinh có thể tham gia lớp, làm bài kiểm tra, xem điểm và theo dõi thông tin lớp học.

1.3. Công nghệ sử dụng

Thành phầnCông nghệ
FrontendNext.js 14, React 18, TypeScript
StylingTailwindCSS, Radix UI, Shadcn/ui
BackendNext.js API Routes
DatabasePostgreSQL + Prisma ORM
AuthenticationClerk
AI IntegrationGoogle Gemini AI, OpenAI, Groq
PWAnext-pwa
QR Codehtml5-qrcode, qrcode
Exportxlsx, file-saver

3.1. Các Model chính

1. User (Người dùng)

TrườngKiểuMô tả

2. Class (Lớp học)

TrườngKiểuMô tả

nameStringTên lớp

3. ClassMember (Thành viên lớp)

TrườngKiểuMô tả

userIdStringID học sinh

4. Quiz (Bài kiểm tra)

TrườngKiểuMô tả

TrườngKiểuMô tả

TrườngKiểuMô tả

TrườngKiểuMô tả

🖥️ V. CÁC TRANG CHÍNH

5.1. Landing Page (/)

  • Giới thiệu ứng dụng với giao diện đẹp mắt
  • Nút đăng nhập/đăng ký

5.2. Dashboard (/dashboard)

  • Hiển thị lớp đang quản lý (cho Giáo viên)
  • Hiển thị lớp đang theo học (cho Học sinh)
  • Hiển thị lớp đang chờ duyệt với badge "Đang chờ"
  • Tạo lớp mới, tham gia lớp bằng mã

5.3. Trang lớp học - Giáo viên (/class/[classId])

Gồm các Tab:

  • Bảng tin: Thông báo, link tài liệu
  • Thành viên: Danh sách học sinh đã duyệt
  • Phòng chờ: Duyệt yêu cầu tham gia (có badge số lượng)
  • Điểm danh: Tạo phiên, xem lịch sử
  • Điểm: Quản lý điểm số theo môn
  • Quiz: Tạo và quản lý bài kiểm tra
  • Thống kê: Tổng quan lớp học

5.4. Trang lớp học - Học sinh (/class/[classId]/student)

Gồm các Tab:

  • Bảng tin: Xem thông báo từ giáo viên
  • Bài kiểm tra: Làm quiz
  • Bảng điểm: Xem điểm
  • Điểm danh: Lịch sử điểm danh

5.5. Trang điểm danh (/attendance)

  • Quét mã QR điểm danh
  • Nhập mã điểm danh thủ công

🔒 VI. PHÂN QUYỀN

Vai tròQuyền hạn
Giáo viên (Owner)Toàn quyền quản lý lớp học của mình: CRUD thành viên, quiz, điểm, điểm danh, thông báo
Học sinh (Approved Member)Xem bảng tin, làm quiz, xem điểm, điểm danh, rời lớp
Pending MemberChỉ xem thông tin cơ bản, chờ duyệt, có thể hủy yêu cầu

🎨 VIII. UI/UX DESIGN

  • Colors: Gradient màu xanh dương, tím, xanh lá

npx prisma db push
npx prisma generate

9.4. Chạy Development

npm run dev

9.5. Build Production

npm run build
npm start

git push origin main
